## 测试过程中发现并修复的缺陷

1. **符号按钮 tooltip 命名缺陷**（真 bug）：符号项缺 `name` 字段时 title 回退成了 LaTeX 命令本身（如 `\cdot：\cdot`）。修复：回退链改为 `name → char → latex`，并为线性代数/微积分组补充中文名（点积、叉积、行列式、偏导数、无穷等）。T5 由此从超时转为通过。
2. **MathLive 自带 UI 噪音**：编辑器内出现虚拟键盘切换按钮。修复：CSS `::part(virtual-keyboard-toggle)` 隐藏（设计评审追加隐藏无标签菜单按钮）。
3. **测试断言过严**（3 处，均为测试缺陷而非应用缺陷）：
   - T3/T4：MathLive 对单字符指数省略花括号、`\\`/`&` 后补空格属语义等价序列化，比较前需规范化；
   - T6：模板按钮按规范在光标处插入（F2），测试未先清空即断言整式相等；
   - T9：宽视口下长公式恰好放得下，不应强制要求实际发生滚动；初版修复遗留 `\|\| true` 恒真断言（sourceScrollable），收尾阶段重写为真实 DOM 检查并拆分 T9a/T9b（见「收尾加固」）。
4. **capture 脚本同步问题**：`setValue` 为程序化赋值，不触发 MathLive 的 `input` 事件；应用全部 UI 路径（按钮/键盘/示例载入）都经 `update()` 自动同步，仅外部脚本需手动派发事件（已在截图脚本中修正）。

## 收尾加固（2026-10-11）

1. **结构面板底行裁切修复**：`.tab-page` 基础规则删除固定 `max-height: 420px`，改内容自适应（全部行完整展开）；窄视口（≤900px）保留内部滚动并补 `padding-bottom`（计入滚动区，末行可完整滚入）。验证 `tests/panel-check.mjs` **3/3**：P1（1400×900）20 按钮 `裁切项=[]`、`maxHeight=none`、无内部滚动；P2（1366×768）同；P3（800×640）图形学面板末行真实滚动可达（lastBottom=693 ≤ 容器底=790）且点击插入 `z_{\mathrm{far}}` 成功。截图证据：`tests/screenshots/after-fix/`（修复前对照存于 `before/`）。
2. **T9 断言重写**：删除 `sourceScrollable` 的 `\|\| true` 恒真断言；`setValue` 后派发 `input`；断言加入「源码已同步」「预览已渲染」，不再可能仅凭赋值成功通过；对源码实测 `scrollWidth/clientWidth/scrollHeight/clientHeight` 与 `scrollTop` 钳制滚到底；预览仅在实际溢出时要求可滚且真实滚到最右。
3. **离线演练 10/10（用户终端实测 2026-10-11）**：条件 = Playwright 路由阻断一切非 127.0.0.1:8642 请求（localhost 保留）+ 全新上下文（空缓存）+ CDP `clearBrowserCache`/`setCacheDisabled` + `serviceWorkers:'block'`。结果：MathLive 正常加载；**零外部请求尝试**；13 个本机响应无 4xx/5xx（favicon 404 未出现）；键盘输入/结构模板/符号/矩阵/预览源码同步/剪贴板复制全部通过；网络审计全部为本机资源（`tests/offline-results.json`）。
4. **离线演练脚本自身缺陷（非应用缺陷）**：D5 点击后未等焦点稳定即键入致丢前两字符（修复：等待 200ms + 实测 `hasFocus()` 断言）；D7 缺「希腊字母」子标签切换致 α 定位超时；D8 未从符号页签切回「结构模板」致矩阵按钮不可见。三处均已修复并由用户终端复跑确认 10/10。
5. **复制导出规范化（用户反馈修复）**：空占位符 `\placeholder{}` 是 MathLive 专有命令，KaTeX/MathJax/ChatGPT 等外部渲染器无法解析（Undefined control sequence）；复制（三种格式）时自动转换为标准 `\square`。应用内编辑行为不变（占位符仍可 Tab 跳转填写）；另补「矩阵乘向量」模板（M·v = 4×1 列向量，修正 4×4 结果形状问题）。
